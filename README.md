# Vrinda Store Data Analysis

## Project Overview

This project analyzes sales data from **Vrinda Store** to understand customer purchasing behavior, sales trends, and business performance. The analysis was performed using **Microsoft Excel** with the help of data cleaning, pivot tables, and visualization techniques.

The goal of the project is to extract actionable insights that can help improve sales strategy, marketing decisions, and customer targeting.

---

## Dataset Description

The dataset contains detailed information about store transactions including:

* Order ID
* Customer demographics (Gender, Age Group)
* Order Date and Month
* Product Category
* Sales Channel (Amazon, Flipkart, Myntra, etc.)
* Order Status
* Quantity
* Sales Amount
* State and Location information

These fields allow analysis of customer behavior and revenue patterns across different dimensions.
